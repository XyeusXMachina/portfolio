# 2. Design Direction

## Overall Style

Use a **clean, minimal, modern portfolio** rather than a highly
futuristic or visually heavy developer portfolio.

### Visual principles

-   Generous whitespace
-   Strong typography
-   White or very light neutral background
-   Black/dark charcoal primary text
-   One restrained green accent
-   Thin borders
-   Subtle rounded corners
-   Minimal shadows
-   Clean line icons
-   Large but controlled typography
-   Strong alignment and consistent spacing
-   Avoid excessive gradients, neon effects, glassmorphism, and
    decorative animations

### Design character

The portfolio should feel: - Professional - Technical -
Research-oriented - Intelligent - Calm - Modern - Human - Precise -
Engineering-focused

It should look appropriate for: - Research positions - AI/ML positions -
Computer vision roles - Intelligent systems engineering - Edge AI
roles - Software/system engineering - Graduate/research applications

# 25. Responsive Design

## Desktop

-   Maximum content width around 1200--1400px
-   Hero uses two balanced columns
-   Four navigation cards in one row
-   Four project cards in a grid
-   Comfortable whitespace

## Tablet

-   Hero remains two-column where space allows
-   Navigation cards become 2×2
-   Projects become 2 columns

## Mobile

-   Single-column layout
-   Portrait below or beside introductory text depending on screen width
-   Navigation becomes compact
-   Four cards stack vertically
-   Project cards stack vertically
-   Keep typography readable
-   Avoid horizontal scrolling

# 26. Interaction Design

Keep interactions subtle.

### Recommended

-   Smooth section scrolling
-   Small hover elevation
-   Border/accent transition
-   Project-card hover state
-   Theme toggle
-   Clear focus states
-   Accessible buttons and links

### Avoid

-   Excessive animations
-   Cursor-following effects
-   Large parallax effects
-   Particle backgrounds
-   Constant motion
-   Overly futuristic UI
-   Excessive gradients
-   Heavy glassmorphism

The portfolio should prioritize **content and credibility** over visual
effects.
